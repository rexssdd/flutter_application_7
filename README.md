# Social Media — reference folder structure

Matches the folder organization shown in SocialMediaOtherOption.html: `lib/auth`, `lib/model`, `lib/views`, `lib/socialmedia.dart`, `lib/main.dart`, and `assets`.

The provided HTML is a tutorial/reference, not a full source project or the original photos. Included assets are clearly generic placeholder images. Replace with your supplied photos as needed.

## Run
Create a Flutter shell first (Android and platform folders are generated by Flutter):

```sh
flutter create .
flutter pub get
flutter devices
flutter run -d YOUR_DEVICE_ID
```

Login is a demo: any nonempty username/password. Comments are saved locally per post with shared_preferences, not on a server. Test on a real device: scrolling, friends alignment, adding comments, closing and reopening, and keyboard appearance. Physical-device execution has not been performed here.
